Конфиг sh1ro (Team Spirit) для CS2: прицел, руки, HUD, мышь

Актуально на 13.11.2026. Прицел — актуальный по pickem.ru (от 11.11.2026). Руки, HUD, радар, мышь и графика — prosettings.net, матч: Spirit vs G2, BLAST Rivals 2026 Season 2, Ancient, 12.11.2026.

Игроки иногда меняют настройки — если увидишь, что прицел поменялся, напиши в чат FunPay, обновлю, ссылка останется той же.

Прицел — код (главное)

CSF68EZcNUK2tnJpxOs4a6YRNmBNMJMBaH5AjAS63CFNqF

Как вставить: Настройки → Игра → Прицел → «Поделиться или импортировать» → «Импорт» → вставь код → Применить. Код ставит прицел точь-в-точь как у игрока.

Как выглядит прицел

  • Цвет: зелёный (R 0, G 255, B 0), прозрачность 255 из 255
  • Стиль: классический статичный (Static); длина 2, толщина 2, зазор 2 (расшифровано из кода)
  • Обводка: нет; точка в центре: нет; T-образный: нет; следует за отдачей: нет

Быстро: одной строкой в консоль

  1. Включи консоль: Настройки → Игра → «Включить консоль разработчика» → Да.
  2. Открой консоль клавишей ` (Ё), вставь строку ниже ЦЕЛИКОМ и нажми Enter.
  3. Строка ставит прицел (по коду), положение рук, HUD, радар и мышь.
apply_crosshair_code CSF68EZcNUK2tnJpxOs4a6YRNmBNMJMBaH5AjAS63CFNqF;viewmodel_fov 68;viewmodel_offset_x 2.5;viewmodel_offset_y 0;viewmodel_offset_z -2;hud_scaling 1.05;cl_radar_always_centered 1;cl_radar_rotate 1;cl_radar_square_with_scoreboard 1;cl_hud_radar_scale 1.05;cl_radar_scale 0.4;sensitivity 1.04;zoom_sensitivity_ratio 1;host_writeconfig

Чувствительность в строке подобрана под мышь с DPI 800. Если у твоей мыши другой DPI — удали из строки кусок «sensitivity 1.04;» или пересчитай: sensitivity = 832 / твой DPI.

Если команда apply_crosshair_code не сработала — вставь код через меню (см. выше), остальное применится.

Положение рук (viewmodel)

  • viewmodel_fov 68
  • viewmodel_offset_x 2.5
  • viewmodel_offset_y 0
  • viewmodel_offset_z -2

HUD и радар

  • Масштаб HUD (hud_scaling): 1.05
  • Цвет HUD: белый — ставится в Настройки → Игра → HUD → Цвет HUD
  • Радар всегда по центру игрока: да; радар вращается: да; квадратный радар с таблицей очков: да
  • Размер радара (cl_hud_radar_scale): 1.05; масштаб карты на радаре (cl_radar_scale): 0.4

Мышь

  • DPI: 800; чувствительность в игре: 1.04; eDPI: 832
  • Чувствительность в прицеле (zoom_sensitivity_ratio): 1; частота опроса: 1000 Гц; Windows: 6/11

Графика (ставится в меню Настройки → Видео)

  • Разрешение: 1280x960, соотношение 4:3, масштабирование: Stretched
  • Яркость: 93%; ограничение FPS в игре: 500
  • Сглаживание (MSAA): 4x MSAA; тени: High, динамические тени: All
  • Детализация моделей/текстур: High; фильтрация текстур: Anisotropic 2x; шейдеры: High; частицы: High
  • Ambient Occlusion: Medium; HDR: Quality; FSR: Disabled (Highest Quality)
  • NVIDIA Reflex: Enabled; усиление контраста игроков (Boost Player Contrast): Enabled

Параметры запуска

  • У игрока: -console +exec autoexec.cfg
  • Параметры -tickrate и -rate в CS2 ничего не делают (остались от CS:GO), -freq ставь только под частоту своего монитора.

Как сохранить навсегда (autoexec)

  1. Открой папку игры: Steam → CS2 → Управление → Просмотреть локальные файлы → game → csgo → cfg.
  2. Создай файл autoexec.cfg (в Блокноте: «Сохранить как» → тип «Все файлы»).
  3. Вставь в него строку из раздела «Быстро: одной строкой в консоль».
  4. В Steam: CS2 → Свойства → Параметры запуска → допиши +exec autoexec.cfg.
